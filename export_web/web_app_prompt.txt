ابنِ تطبيق ويب حديث ومتكامل باسم «نسمة الحياة 🌿» (مساحة عربية آمنة للتوعية النفسية والسكينة والمساعدة الذاتية) باستخدام React و Tailwind CSS و TypeScript و Lucide Icons.

المواصفات الفنية والتصميم:
1. واجهة عربية كاملة RTL بالخطوط العربية الأصيلة (Cairo / Tajawal).
2. باليتة ألوان دافئة ومريحة للأعصاب: أخضر غابي داكن (#2D5A43)، أخضر مريمي (#5A8A6E)، نعناعي ناعم (#D4EAD9)، وخلفية كريمية دافئة (#F8F6F0).
3. شاشة رئيسية تفاعلية تتضمن:
   - تسجيل الحالة النفسية اليومية (Daily Check-in) وتحديد المشاعر.
   - «شجرة الطمأنينة الحية» التي تنمو وتزدهر أوراقها مع كل نشاط أو تمرين يقوم به المستخدم.
   - متتبع عادات التعافي اليومية (Daily Habits Tracker) مع شريط تقدم حي وحفظ محلي في LocalStorage وإمكانية إضافة عادات جديدة.
4. تمرين التأريض الحسي 5-4-3-2-1 (Grounding Tool) لعلاج نوبات الهلع والقلق الحاد خطوة بخطوة بالتحفيز الحسي.
5. مفكرة الامتنان والمشاعر (Gratitude & Feelings Journal) مع منتقي الرموز التعبيرية والتصنيف بوسوم وحفظ الخواطر محلياً.
6. «واحة الأصوات المحيطية» (Sound Oasis) مع مشغل ومولد أصوات طبيعية (صوت المطر، أمواج البحر، ترددات 432Hz للسكينة) ومؤقت نوم ذكي (Sleep Timer).
7. مكتبة المحتوى والتمارين مع تصنيفات تفاعلية كاملة تشمل:
   - تمارين وتطبيقات عملية (تفريغ الغضب بالورقة والقلم، فك أسر الأفكار، الاسترخاء العضلي PMR، استراتيجية STOP).
   - الورش التطبيقية العشرة الكاملة (صندوق الأدوات النفسية، خطة الإنقاذ، التعامل مع التفكير الزائد، إلخ).
   - العلاقات الإنسانية والتعافي من الخذلان.
   - الأسرة والتربية الواعية بدون احتراق نفسي.
   - القلق والضغط والتمييز بين دائرة السيطرة ودائرة القلق.
8. تجربة استخدام متجاوبة (Mobile-First) تعمل بسلاسة على الهواتف والأجهزة اللوحية والكمبيوتر المكتبي بدون أي مكتبات مفقودة.
